# Selenium Automation Testing Project

## Project Overview

This project demonstrates the automation testing of a Registration Form web application using Selenium WebDriver and Java.
The objective of this project is to automate functional test scenarios, validate user inputs, verify error messages, 
and ensure the application behaves as expected under different conditions.The automation scripts simulate 
real user interactions such as entering data, selecting options, submitting forms, and validating application responses.


## Technologies Used

- Java
- Selenium WebDriver
- TestNG
- Maven
- VS Code

## Testing Scope

The project covers functional testing and validation of a Registration Form application.

### Automated Test Cases

### 1. Name Field Validation
- Verify valid name input is accepted
- Verify mandatory field validation
- Verify appropriate error messages are displayed

### 2. Email Validation
- Verify valid email format
- Verify invalid email format handling
- Verify required field validation

### 3. Password Validation
- Verify password length requirements
- Verify password validation messages
- Verify mandatory field validation

### 4. Gender Selection Validation
- Verify radio button selection
- Verify mandatory gender selection validation

### 5. Department Dropdown Validation
- Verify dropdown selection functionality
- Verify mandatory dropdown selection validation

### 6. Error Message Verification
- Verify validation messages for invalid inputs
- Verify mandatory field error messages

### 7. Form Submission Validation
- Verify successful registration
- Verify successful form submission message

### 8. User Interface Verification
- Verify important form elements are displayed
- Verify form controls are accessible


## Project Execution

The automation suite performs the following actions:

1. Launches the browser
2. Opens the Registration Form application
3. Performs user interactions
4. Validates application responses
5. Verifies expected results
6. Generates execution results
